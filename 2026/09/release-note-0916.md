# BigQuery
## Change
原文: `An updated version of the Simba ODBC driver for BigQuery is now available.`
[Simba ODBC driver for BigQuery](https://docs.cloud.google.com/bigquery/docs/reference/odbc-jdbc-drivers#current_odbc_driver)

説明：
BigQueryへ外部アプリケーションから接続するための「Simba ODBCドライバ」の最新バージョンがリリースされたことを示すアナウンスです。このドライバは、TableauやPower BIなどのビジネスインテリジェンス（BI）ツールやカスタムアプリケーションがBigQueryにODBC経由で接続し、データにアクセスするために利用されます。

影響有無：
**既存環境への直接的な影響は軽微です。**
この変更はBigQueryサービス本体の更新ではなく、クライアント側で利用するODBCドライバの提供に関するものです。そのため、現在BigQueryを利用している既存のアプリケーションやワークロードが直ちに動作を停止するなどの影響はありません。

ただし、BigQueryへODBC接続を利用しているお客様環境においては、パフォーマンスの向上、安定性の改善、セキュリティ修正、または新しい機能のサポートなど、最新のドライバで提供されるメリットを享受するためには更新を検討することが推奨されます。本リリースノートでは非互換性の変更（Breaking Change）については明記されていませんが、重要な更新が含まれる可能性もあります。

対処方法：
BigQueryへODBC接続を利用している環境（例: BIツール、カスタムアプリケーション）において、**最新の機能、パフォーマンス改善、安定性向上、またはセキュリティ修正が必要な場合**は、Simba ODBCドライバの更新を検討してください。

1.  更新を行う際は、まず非本番環境で十分な動作確認を実施し、既存のデータ接続やクエリに影響がないことを確認してください。
2.  ドライバのダウンロードは、公式ドキュメントの[Simba ODBC driver for BigQuery](https://docs.cloud.google.com/bigquery/docs/reference/odbc-jdbc-drivers#current_odbc_driver)を参照してください。

用語説明：
*   **ODBC (Open Database Connectivity)**: データベースにアクセスするための標準的なAPI（Application Programming Interface）です。これにより、アプリケーションは特定のデータベースシステムに依存することなく、さまざまな種類のデータベースに接続できるようになります。
*   **Simba Technologies**: データ接続ソリューションを専門とする企業です。多くの主要なデータベースやクラウドサービス向けに、ODBCやJDBC（Java Database Connectivity）といった標準に準拠した高品質なドライバを提供しており、BigQuery向けのODBCドライバも同社が開発しています。
