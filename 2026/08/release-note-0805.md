# BigQuery

## Announcement

原文: Support for hybrid search (using the `VECTOR_SEARCH` function to combine a semantic search with a lexical (keyword) search) has been restored. Using `HYBRID` mode in the `AI.SEARCH` function has also been restored.

説明：
BigQuery におけるハイブリッド検索機能のサポートが復元されました。これには、`VECTOR_SEARCH` 関数を使用してセマンティック検索とキーワード検索（レキシカル検索）を組み合わせる機能と、`AI.SEARCH` 関数における `HYBRID` モードの利用が含まれます。以前、これらの機能が一時的に利用できない状態でしたが、再び利用可能になりました。

影響有無：
影響はありません。これは、以前一時的に利用できなかった機能が復元され、再び利用可能になったというアナウンスです。既存の BigQuery サービスやデータに悪影響を与えるものではなく、むしろ利便性が向上します。

対処方法：
既存のシステムに対する直接的な対処は不要です。この機能を利用したい場合は、BigQuery のドキュメントを参照し、必要に応じてアプリケーションでの実装を検討してください。

用語説明：
*   **ハイブリッド検索 (Hybrid Search)**: 意味に基づいたセマンティック検索と、キーワードのマッチングに基づいたレキシカル検索（キーワード検索）の両方を組み合わせて、より網羅的で関連性の高い検索結果を得るための手法です。
*   **`VECTOR_SEARCH` 関数**: BigQuery ML で提供される関数の一つで、ベクトルデータ間の類似度検索を実行するために使用されます。これにより、テキストや画像などの非構造化データから生成されたベクトル間の類似性に基づいてデータを検索できます。
*   **`AI.SEARCH` 関数**: BigQuery ML の一部として提供される、AI ベースの検索機能を実現する関数群です。`HYBRID` モードは、この関数内でハイブリッド検索を有効にするためのオプションです。

# Cloud SQL for PostgreSQL

## Change

原文: You can change the backup plan for your Cloud SQL enhanced backups without first removing the existing plan. For more information, see Change your instance's associated backup plan.

説明：
Cloud SQL for PostgreSQL の拡張バックアップ (enhanced backups) において、既存のバックアッププランを削除することなく、直接変更できるようになりました。これにより、バックアッププランの更新プロセスが簡素化され、運用上の利便性が向上します。

影響有無：
影響はありません。この変更は、Cloud SQL の拡張バックアッププランを管理する際の操作手順の改善であり、既存のバックアップ設定やバックアップの動作に悪影響を与えるものではありません。現在稼働中のバックアップには影響せず、バックアップの継続性も保たれます。

対処方法：
既存のシステムに対する直接的な対処は不要です。今後、Cloud SQL for PostgreSQL インスタンスの拡張バックアッププランを変更する際には、提供されたドキュメントを参照し、新しい簡素化された手順を利用することができます。

用語説明：
*   **Cloud SQL enhanced backups**: Cloud SQL が提供する高度なバックアップ機能で、通常の自動バックアップに加えて、より細かいリカバリポイントの指定（Point-in-Time Recovery: PITR）や、長期保存などのオプションを提供します。ログベースのバックアップにより、特定の時点への復元を可能にします。
*   **バックアッププラン (Backup Plan)**: Cloud SQL enhanced backups において、バックアップの頻度、保持期間、ストレージタイプなどのポリシーを定義する設定のことです。
