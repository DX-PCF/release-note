ExtendedチャネルにおけるGKEのバージョン更新が行われました。主な変更点は以下の通りです。
- クラスタ作成時のデフォルトバージョンが `1.33.2-gke.1240000` に更新されました。
- 新しいGKEバージョンがExtendedチャネルで利用可能になり、古いバージョンが利用不可となりました。
- 自動アップグレードのターゲットバージョンが更新され、各マイナーバージョンからのアップグレード先が指定されました。これには、パッチバージョンのみのアップグレードターゲットも含まれます。
影響有無:
影響あり。
- Extendedチャネルで新規クラスタを作成する場合、デフォルトバージョンが変更されます。
- Extendedチャネルで自動アップグレードを有効にしている既存クラスタは、指定されたターゲットバージョンにアップグレードされる可能性があります。これにより、ワークロードの互換性確認が必要となる場合があります。
- 特定のバージョンに固定している場合、利用不可になったバージョンへの新規作成やダウングレードはできなくなります。
対処方法:
- Extendedチャネルでクラスタを運用している場合、メンテナンスウィンドウと自動アップグレード設定を確認し、対象のターゲットバージョンへのアップグレード計画を立ててください。
- アップグレード対象のバージョンへの互換性テストを実施し、ワークロードへの影響がないか確認してください。
- 新規クラスタを作成する際は、デフォルトバージョンまたは利用可能なバージョンの中から、要件に合ったバージョンを選択してください。
用語説明:
- **Extended channel**: GKEのリリースチャネルの一つで、長期間サポートされる安定版のバージョンを提供するチャネルです。
- **Auto-upgrade targets**: GKEクラスタのコントロールプレーンおよびノードが自動的にアップグレードされる際の目標バージョンです。
- **Maintenance exclusions**: GKEクラスタのメンテナンス（自動アップグレードなど）が実行されない期間を設定する機能です。

# BigQuery
## Changed
原文: BigQuery ML has improved throughput by more than 100x for the following generative AI functions: `ML.GENERATE_TEXT`, `AI.GENERATE_TABLE`, `AI.GENERATE`, `AI.GENERATE_BOOL`, `AI.GENERATE_DOUBLE`, `AI.GENERATE_INT`. Actual performance varies based on the number of input and output tokens in the request, but a typical 6-hour job can now process millions of rows.
説明: BigQuery MLで提供される生成AI関数（`ML.GENERATE_TEXT`、`AI.GENERATE_TABLE`、`AI.GENERATE`、`AI.GENERATE_BOOL`、`AI.GENERATE_DOUBLE`、`AI.GENERATE_INT`）のスループットが100倍以上に向上しました。これにより、これまで6時間かかっていたジョブで数百万行のデータ処理が可能になるなど、大規模な処理の効率が大幅に改善されます。
影響有無: 影響なし。既存の利用方法を変更することなく、これらの関数を利用するクエリのパフォーマンスが向上します。非互換な変更は含まれていません。
対処方法: なし。

## Changed
原文: BigQuery ML now can automatically detect model quota increases in Vertex AI, and automatically adjusts the quota for any BigQuery ML functions that use those models. You no longer need to email the BigQuery ML team to increase model quota.
説明: BigQuery MLがVertex AIのモデルクォータの増加を自動的に検出し、そのモデルを使用するBigQuery ML関数のクォータを自動的に調整するようになりました。これにより、BigQuery MLモデルのクォータ上限引き上げリクエストをBigQuery MLチームにメールで申請する必要がなくなります。
影響有無: 影響なし。既存の運用ワークフローが改善されるため、管理負担が軽減されます。システム動作への影響はありません。
対処方法: なし。
用語説明:
*   **モデルクォータ**: Google CloudのサービスやAPIの使用量に設定された上限値。機械学習モデルの呼び出し回数などに適用されます。
*   **Vertex AI**: Google Cloudの機械学習プラットフォーム。機械学習モデルの開発、デプロイ、管理を統合的に行えます。

# Pub/Sub
## Libraries
原文: General availability: The Ruby Pub/Sub client library has a new major version. For more information on how to migrate from v2 to v3, see the Migration guide.
## Deprecated
原文: `google-cloud-pubsub/v2.x`
説明: Ruby版のPub/Subクライアントライブラリがメジャーバージョンアップし、v3が一般提供（GA）されました。これに伴い、従来のv2.x系は非推奨（Deprecated）となります。v2からv3への移行ガイドが公開されています。
影響有無: 影響の可能性あり。Google Cloud Composer2はPythonベースであり、Rubyクライアントライブラリを直接使用することはありません。しかし、もし別途Rubyで開発されたアプリケーションがPub/Subを利用しており、`google-cloud-pubsub` v2.xを使用している場合は影響があります。
対処方法:
*   システム内でRubyのPub/Subクライアントライブラリv2.xを使用しているアプリケーションがないか確認してください。
*   もし使用している場合は、[公式の移行ガイド](https://github.com/googleapis/google-cloud-ruby/blob/main/google-cloud-pubsub/MIGRATION_GUIDE.md)を参照し、v3へのアップグレードを計画・実施してください。
用語説明:
*   **クライアントライブラリ**: プログラミング言語（この場合はRuby）からGoogle Cloudサービス（この場合はPub/Sub）のAPIを容易に利用できるように提供されるSDKの一部です。
*   **メジャーバージョン**: ソフトウェアのバージョン管理において、互換性のない変更を含む大きなバージョンアップを示します（例: v2からv3への変更）。
*   **一般提供（GA: General Availability）**: プロダクトや機能が公式に安定版としてリリースされ、SLA（サービスレベル契約）の対象となる状態です。
*   **非推奨（Deprecated）**: その機能やバージョンが将来的にサポートされなくなる可能性があることを示します。新しい開発での使用は推奨されず、既存の利用者は移行が推奨されます。

# Spanner
## Changed
原文: You can use continuous queries to export BigQuery data into Spanner in real time. This feature is in preview.
説明: BigQueryのデータをSpannerにリアルタイムでエクスポートするための「継続クエリ」機能が、プレビュー版として利用可能になりました。
影響有無: 影響なし。新機能の追加であり、既存のSpannerの利用方法に直接的な変更や影響を与えるものではありません。この機能を利用しない限り、特別な対応は不要です。
対処方法: なし。この新機能を評価・利用したい場合は、[関連ドキュメント](https://cloud.google.com/bigquery/docs/export-to-spanner)を参照し、プレビュー機能であることに留意して導入を検討してください。
用語説明:
*   **継続クエリ (Continuous Queries)**: データストリームに対して常時実行され、新しいデータが到着するたびに結果を更新するタイプのクエリです。
*   **プレビュー (Preview)**: Google Cloudのプロダクトや機能が一般公開される前のテスト段階です。機能が変更される可能性があり、SLAは適用されません。

## Libraries
### Java
原文: Changes for `google-cloud-spanner` versions 6.96.1, 6.97.0, 6.97.1. Includes dependency updates, dropping max message size, and returning non-empty metadata for DataBoost queries.
説明: Java版Spannerクライアントライブラリ `google-cloud-spanner` の複数のバージョン（6.96.1、6.97.0、6.97.1）がリリースされました。主な変更点として、依存ライブラリの更新、最大メッセージサイズ制限の緩和、DataBoostクエリにおける非空メタデータの返却などが含まれます。
影響有無: 影響なし。Google Cloud Composer2はPythonベースであるため、Javaクライアントライブラリは直接利用していません。
対処方法: なし。もしJavaアプリケーションでSpannerを利用している場合は、これらのリリースノートを確認し、必要に応じてライブラリのアップグレードを検討してください。
用語説明:
*   **DataBoost**: Spannerの機能の一つで、分析クエリやバッチ処理のような大規模な読み込み操作を、通常のトランザクション処理から分離し、リソース競合を避けることでパフォーマンスの安定化を図ります。

### Python
原文: Changes for `google-cloud-spanner` version 3.56.0. Includes adding support for multiplexed sessions (default enabled), adding `change_stream.proto`, and skipping gRPC trailers for streaming reads.
説明: Python版Spannerクライアントライブラリ `google-cloud-spanner` のバージョン3.56.0がリリースされました。主な変更点は以下の通りです。
*   **多重化セッション (Multiplexed Sessions)** のサポート追加と、デフォルトでの有効化（明示的に無効にしない限り有効になります）。
*   Spannerの変更ストリーム機能に関連する `change_stream.proto` の追加。
*   `StreamingRead` および `ExecuteStreamingSql` におけるgRPCトレーラーのスキップ。
影響有無: 影響の可能性あり。Google Cloud Composer2 (Airflow) はPythonベースであり、DAG内でPythonOperatorやカスタムオペレータを通じてSpannerのPythonクライアントライブラリを利用している場合、影響を受ける可能性があります。
*   **多重化セッションのデフォルト有効化**: パフォーマンス向上が期待されますが、セッション管理やエラーハンドリングの挙動が既存の実装とわずかに異なる可能性があるため、注意が必要です。
*   その他の変更は新機能追加や内部的な改善であり、既存のコードへの直接的な影響は少ないと考えられます。
対処方法:
*   Composer2環境内でSpannerのPythonクライアントライブラリを使用しているDAGやカスタムオペレータが存在するか確認してください。
*   もし使用している場合は、ライブラリをv3.56.0にアップグレードする際に、**多重化セッションのデフォルト有効化**による影響がないか、特にセッションのライフサイクル管理やエラー処理の観点から、テスト環境で十分に検証を実施してください。
*   万が一問題が発生した場合は、多重化セッションを明示的に無効化するオプション（もし提供されていれば）の利用を検討してください。
用語説明:
*   **多重化セッション (Multiplexed Sessions)**: Spannerクライアントライブラリの機能で、複数のトランザクションやクエリを効率的に処理するために、単一のネットワーク接続上で複数の論理的なセッションを多重化する技術です。これにより、セッション管理のオーバーヘッドを削減し、スループットとレイテンシの向上が期待されます。
*   **`change_stream.proto`**: Spannerの変更ストリーム機能（データベースのデータ変更をリアルタイムでキャプチャする機能）に関連するProtocol Buffer定義ファイルです。
*   **gRPCトレーラー (gRPC trailers)**: gRPC通信において、レスポンスメッセージの最後に付加されるメタデータで、ステータスコードや追加情報などが含まれます。
