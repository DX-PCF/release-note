
# Title: October 08, 2026 
Link: https://docs.cloud.google.com/release-notes#October_08_2026<br>
## Google Kubernetes Engine

### Change
原文: GKE cluster versions have been updated. New versions available for upgrades and new clusters.
説明: Google Kubernetes Engine (GKE) のクラスタバージョンが更新され、新しいバージョンがアップグレードおよび新規クラスタ作成で利用可能になりました。特定のGKEバージョンが、各リリースチャネル（Stable, Regular, Rapid, Extended）およびNo channel (deprecated)において、デフォルトバージョンとして設定されたり、新規に利用可能になったりしています。また、一部の古いバージョンは非推奨となり、90日以内に削除される予定です。
影響有無: 有り。
理由:
*   **新規クラスタ作成**: 新しいデフォルトバージョンでクラスタが作成されます。これにより、最新の機能やセキュリティ修正が適用されたクラスタを最初から利用できます。
*   **既存クラスタのアップグレード**: GKEクラスタは設定されたリリースチャネルに基づき、自動アップグレードの対象となる可能性があります。メンテナンスウィンドウや除外設定によっては、計画外のアップグレードが発生する可能性があります。
*   **非推奨バージョン**: 現在利用中のGKEクラスタが非推奨となったバージョンを使用している場合、90日以内に強制的にアップグレードされるか、サポートが終了する可能性があります。計画的なアップグレードが必要です。
*   **Google Cloud Composer2 (Compoer version 2.7.1、Airflow version 2.7.3)**: ComposerはGKEクラスタ上に構築されているため、Composer環境が稼働しているGKEのバージョンに間接的に影響します。Composer自体が内部的に使用するGKEバージョンを管理しているため、Composerの将来のメンテナンスリリースやマイナーバージョンアップで、これらの新しいGKEバージョンが採用される可能性があります。非推奨バージョンを使用している場合、Composerのアップデートが必要になる場合があります。
対処方法:
1.  **現在のGKEクラスタバージョンの確認**: お使いのGKEクラスタのバージョンおよび所属しているリリースチャネルを確認してください。
2.  **非推奨バージョンの確認**: もし非推奨となったバージョン（例: `1.34.11-gke.1044000`など）を使用している場合は、90日間の猶予期間内にサポートされているバージョンへのアップグレード計画を立ててください。
3.  **自動アップグレード設定の確認**: クラスタのメンテナンスウィンドウや除外設定を確認し、自動アップグレードがビジネス要件に合致しているかを確認してください。必要に応じて、アップグレードが実行される時間帯を調整してください。
4.  **互換性テスト**: マイナーバージョンアップやパッチバージョンアップであっても、アプリケーションの互換性問題を避けるため、事前にステージング環境などでアップグレード後の動作テストを実施することを強く推奨します。特にKubernetes APIの非推奨化や削除に関する変更に注意してください。

### Security
原文: This release includes new GKE versions that use updated Container-Optimized OS images. These updated images are cumulative, incorporating security fixes from all Container-Optimized OS versions released since the previous GKE release.
説明: 今回のGKEリリースに含まれる新しいバージョンでは、更新されたContainer-Optimized OS (COS) イメージが使用されています。これらのイメージは、前回のGKEリリース以降に公開されたすべてのCOSバージョンからのセキュリティ修正を累積的に含んでいます。リリースノートには、各GKEバージョンとそれに対応するCOSバージョン、およびCOSのリリースノートへのリンクが記載されています。
影響有無: 有り（ポジティブな影響）。
理由: GKEノードの基盤となるContainer-Optimized OSのセキュリティが強化されます。これにより、クラスタ全体のセキュリティ体制が向上し、既知の脆弱性からの保護が強化されます。
対処方法:
1.  **GKEクラスタのアップグレード**: GKEクラスタを新しいバージョンにアップグレードすることで、自動的に更新されたContainer-Optimized OSイメージがノードに適用されます。これにより、最新のセキュリティ修正が反映されます。
2.  **Google Cloud Composer2**: Composer環境のGKEノードも同様に、ComposerのバージョンアップグレードやGKEの自動アップグレードによって基盤OSのセキュリティが強化されます。

### 用語説明
*   **GKEチャネル (Release Channels)**: GKEクラスタのKubernetesバージョン更新頻度と安定性を示す設定。通常、Stable, Regular, Rapid, Extendedのチャネルがあり、それぞれ更新のペースと新機能の導入時期が異なります。
    *   **No channel (deprecated)**: 以前のGKEのバージョン管理方法であり、特定のリリースチャネルに属さない状態。現在は非推奨とされており、チャネルへの移行が推奨されます。
*   **Deprecated (非推奨)**: 今後サポートが終了し、最終的に削除される予定の機能やバージョンを指します。非推奨とされたものは、代替手段への移行が強く推奨されます。
*   **Container-Optimized OS (COS)**: Googleによって最適化された、コンテナの実行に特化したLinuxベースのオペレーティングシステム。GKEノードの基盤OSとして利用され、セキュリティ、安定性、パフォーマンスが考慮されています。
*   **メンテナンスウィンドウ (Maintenance Window)**: GKEクラスタの自動アップグレードなどのメンテナンスアクティビティが実行されることを許可する時間帯。ユーザーが指定可能で、ワークロードへの影響を最小限に抑えるために設定されます。
*   **メンテナンス除外 (Maintenance Exclusions)**: 特定の期間、自動アップグレードなどのメンテナンスアクティビティを一時的に停止させる設定。長期的な安定稼働が必要な期間に利用されます。
